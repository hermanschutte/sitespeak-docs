<Accordion title="Video transcript">
Visitors on your website have questions. What does this cost? Do you ship to my country? How do I talk to a person?

A SiteSpeak AI agent can answer these questions for you, at any time. You do not need to write code. This video shows how to make the agent, test it, and add it to any website. It also shows how to collect leads, and how to make the answers better.

Step 1. Make the agent. Log in to SiteSpeak. Type a name for your agent. Type the URL of your website. SiteSpeak finds your pages and selects the main pages for you. Click Save and Continue. SiteSpeak trains the agent on these pages. This takes a few minutes.

Step 2. Test the agent. Before you add the agent to your website, test it. Open Test Agent. Ask three questions that your visitors ask. For example, ask about prices, shipping, and contact details. Read each answer. If an answer is not correct, add the missing information in Training and Content.

Step 3. Brand the agent. Open Appearance. Set the Accent Color to your brand color. Under Icons, upload your logo. Type a Welcome Message. For example: Hi, ask me about our products, prices, or shipping. Now the agent looks like part of your website.

Step 4. Add the agent to your website. Open Install Agent, and copy the JavaScript code snippet. Paste the snippet in the head section of your website. Then save or publish your website. Most website builders have a setting for custom code. For example, Code Injection in Squarespace, or Custom Code in Framer. The chat button is now on your website. The SiteSpeak docs have a step-by-step guide for more than 100 website builders.

Step 5. Collect leads. Open Settings, and go to the Leads tab. Turn on Enable Lead Capture. Add the fields that you need, for example name and email. Now the agent asks for these details before the chat starts. You can see each lead in Contacts. Lead capture is available on the paid plans.

Step 6. Send difficult questions to your team. Some questions need a person. For example, a custom order, or a complaint. Open Settings, and go to Escalations. Turn on Enable Escalations. Type the email address of your team. When a visitor asks for a person, the agent sends the conversation to your team. You can read and reply to all conversations in the Inbox. Escalations are available on the Pro plan and higher.

Step 7. Make the answers better. Open the Dashboard. Look at Top Unanswered Questions. These are the questions that the agent could not answer. For each question, add the missing information. Or add an Updated Answer. Do this each week. Then the agent can answer more questions each week.

You can start with a free plan at sitespeak.ai.
</Accordion>

## Quick Install (Any Website)

The fastest way to add your chatbot to any website is with our embed script. Simply add this code to your website's HTML:

```html
<script type="text/javascript">
  (function(){
    d=document;
    s=d.createElement("script");
    s.src="https://sitespeak.ai/chatbots/YOUR_CHATBOT_ID.js";
    s.async=1;
    d.getElementsByTagName("head")[0].appendChild(s);
  })();
</script>
```

Replace `YOUR_CHATBOT_ID` with your actual chatbot ID, which you can find in your [dashboard](https://sitespeak.ai/dashboard) under **Install Agent**.

<Note>
  Does your website use a strict Content Security Policy without `'unsafe-inline'`? The widget supports CSP nonces. See the [CSP integration guide](/advanced/content-security-policy) for the one-line addition to the snippet.
</Note>

<Note>
  Using the **Auto** theme but want one page to always show the light or dark version? Add `s.dataset.theme="light";` (or `"dark"`) to the snippet before the `appendChild` line, or put `data-theme="light"` on a plain script tag. See [theme settings](/managing-your-chatbot/appearance#pinning-the-theme-on-a-specific-page).
</Note>
