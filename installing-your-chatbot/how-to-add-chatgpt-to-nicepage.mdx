You want to embed your custom trained AI support agent in your **Nicepage** website page. Here's how to add an AI support agent to Nicepage with SiteSpeakAI.

Nicepage is a web design platform that allows you to create websites and landing pages visually, without coding. It offers a drag-and-drop interface and a range of pre-designed templates.

You can learn more at: [Nicepage](https://nicepage.app/)

## Add your AI support agent to your **Nicepage** website

<InstallCopyCode />

### In Nicepage

1. Log into your Nicepage account and on the dashboard, select **Site Operations** for the Project you want to add your AI agent to
![](/images/installing-your-chatbot/Nicepage/1-Log-into-your-acc-and-select-Site-Ops.png)

2. Select **Site Settings**
![](/images/installing-your-chatbot/Nicepage/2-Select-Site-Settings.png)

**Please note**:

In the next step you will have to edit the snippet you copied earlier in this tutorial. Nicepage doesn’t allow the full standard SiteSpeakAI snippet to be added to the website, only the JavaScript code snippet. This means you will have to remove the Comment lines that were added by SiteSpeakAI, i.e. the starting comment line: `<!-- SiteSpeakAI - Add ChatGPT to your website -->` as well as the ending comment line: `<!-- / SiteSpeakAI -->` leaving you with only the script code part, i.e. the `<script type="text/javascript">` .... `</script>` part of the Javascript snippet.

3. On the Site Settings page select **HTML**, insert your AI agent snippet in the **Additional Head HTML** text box, apply the edits as shown and click on **Done**
![](/images/installing-your-chatbot/Nicepage/3-Insert-snippet-remove-lines-and-done.png)

4. Go back to **Site Operations** on your dashboard and click on **Publish**
![](/images/installing-your-chatbot/Nicepage/4-Click-on-Publish.png)

5. Your AI support agent button will now be displayed on your **Nicepage** website page
![](/images/installing-your-chatbot/Nicepage/5-Chatbot-button.png)

6. If you click on the button it will display the AI support agent dialogue
![](/images/installing-your-chatbot/Nicepage/6-Chatbot-dialogue.png)

Your AI support agent has now been added to your **Nicepage** website and your visitors/customers can start interacting with it!
