## Add your AI support agent to your Wix website

<InstallCopyCode />

### In Wix

1. In the Wix Editor, click **Add Elements** (the plus icon)

![1-Wix-Add-a-new-element](/images/installing-your-chatbot/Wix/1-Wix-Add-a-new-element.png)

2. Select **Embed Code**, then choose **Custom Code** under **Marketing Tools**

![2-Wix-Add-the-Custom-Code-Element](/images/installing-your-chatbot/Wix/2-Wix-Add-the-Custom-Code-Element.png)

3. Click **Add Code** in the **Head** section of the Custom Code dialog

![3-Wix-Custom-Code-Modal](/images/installing-your-chatbot/Wix/3-Wix-Custom-Code-Modal.png)

4. Paste your AI support agent code snippet into the **Add Custom Code** modal
   - Give it a name to identify it easily (here we gave it "MuconSA Customer Support" as the name for the purpose of this tutorial)
   - Choose whether to display on **All pages** or a specific page

5. Click **Apply** to save your changes

![4-Wix-Custom-Code-Entry](/images/installing-your-chatbot/Wix/4-Wix-Custom-Code-Entry.png)

<Note>
The AI support agent will only appear on your published site, not in the Wix Editor preview. You must publish your changes to see the AI support agent.
</Note>

6. Click on **Publish** to publish your changes to your live website

![5-Wix-Publish-site](/images/installing-your-chatbot/Wix/5-Wix-Publish-site.png)

7. Your AI support agent button will now appear on your live website

![6-Wix-Chatbot-Button](/images/installing-your-chatbot/Wix/6-Wix-Chatbot-Button.png)

8. Visitors can click the button to open the AI support agent dialogue and start asking questions

![7-Wix-Chatbot-Dialogue](/images/installing-your-chatbot/Wix/7-Wix-Chatbot-Dialogue.png)

## Alternative: Using an HTML embed

If you prefer to embed the AI support agent in a specific location on your page rather than as a floating widget:

1. In the Wix Editor, click **Add Elements** > **Embed Code** > **Embed HTML**
2. Drag the HTML widget to where you want the AI support agent to appear
3. Click **Enter Code** and paste the iFrame embed code from SiteSpeakAI
4. Resize the embed box as needed
5. Publish your site

This method is useful if you want the AI support agent to appear inline within your page content rather than as a floating button.

## Mobile responsiveness

The SiteSpeakAI support agent widget is fully responsive and works on all devices. On mobile, the chat button automatically adjusts its position to avoid interfering with navigation elements. You can customize the mobile position offset in your SiteSpeakAI dashboard if needed.

## Troubleshooting

**AI support agent not appearing after publishing?** Clear your browser cache and reload the page. Wix may cache your site for performance.

**Custom Code option not available?** Make sure you have a Wix Premium plan. Custom code features are not available on free Wix sites.

**Chatbot appears in wrong position?** Adjust the position and offset settings in your SiteSpeakAI appearance settings. You can position the widget in any corner and set custom margins.

**Preview not showing the chatbot?** This is expected behavior. Wix's preview mode doesn't load custom code. You must publish your site to see the chatbot.
